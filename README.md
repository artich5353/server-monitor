# server-monitor
Скрипт мониторинга серверов с уведомлением через Telegram.

## Планируемые функции
- читает список проверок из YAML-конфига (доступность хостов по ping и HTTP,
  занятость диска и памяти, состояние сервисов);
- пишет понятный лог и возвращает корректные коды выхода;
- отправляет отчёт и алерты в Telegram;
- запускается по расписанию (cron или systemd timer);
- живёт в Git-репозитории с нормальной структурой, README и историей коммитов.
